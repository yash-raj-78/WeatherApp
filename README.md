Weather App 🌦️📱

A sleek and user-friendly Android application built with Kotlin that provides real-time weather updates for any location around the world.

🚀 Features
Real-time weather updates
Search weather by city name
Displays temperature, humidity, and weather conditions
Clean and responsive UI
REST API integration for live data fetching
Fast and smooth performance

🛠️ Tech Stack
Language: Kotlin
IDE: Android Studio
Networking: REST API
API Handling: Retrofit / Volley
UI Design: XML Layouts

⚙️ Installation / Setup
Clone the repository
Open the project in Android Studio
Add your Weather API key
Sync Gradle files
Run the app on an Android device or emulator

🌍 Usage
Open the app
Search for any city worldwide
View live weather details instantly
Track temperature, humidity, and atmospheric conditions in real time
